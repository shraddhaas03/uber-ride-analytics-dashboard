# uber-ride-analytics-dashboard
An interactive Power BI dashboard analyzing Uber booking trends, cancellations, customer behavior, ride patterns, and operational performance.

#Project Overview
This project analyzes Uber ride booking data from Bangalore (Bengaluru) using Power BI. The dataset contains approximately 103K booking records and includes information such as booking status, vehicle type, pickup and drop locations, cancellation reasons, booking value, ride distance, customer and driver ratings, and arrival times.

The dashboard was developed to identify booking trends, cancellation patterns, customer behavior, vehicle performance, and key operational insights through interactive data visualization.
